24/7 server

Keep copying while you sleep

Your PC goes to sleep, the trades don't. Put the server on any spare Windows PC on your network and leave it running. The desktop app becomes a remote control.

  1. Download FomoTradingbotServer.exe on the spare PC and double-click it. Allow it through Windows Firewall when asked.
  2. Pair: in the desktop app go to Settings → Find servers, pick the PC and type the 6-digit code shown in the server window.
  3. Set it and forget it: press S in the server window to start it with Windows. It keeps the PC awake while it runs.

FAQ

Questions

Is this the official fomo app?

No. Fomo Tradingbot is an independent, unofficial tool and is not affiliated with or endorsed by Fomo Labs. It uses your own fomo login (in a fomo.family window) only to look traders up.

Do I need a fomo account?

Only to search users and view fomo profiles — fomo shows those to signed-in users. Copying itself runs on-chain, so you can also copy any Solana wallet without signing in.

Which chains are copied?

Solana. That's where most fomo trading happens. Profiles show holdings on other chains too, but only Solana trades are mirrored.

Where does my private key go?

Nowhere. Import a dedicated trading wallet in Settings; the key is encrypted with a key unique to the machine running the bot. When you pair with a server, the key travels across your LAN encrypted with that pairing's secret.

Windows says "Windows protected your PC".

The .exe isn't code-signed yet, so SmartScreen warns on first launch. Click More info → Run anyway. The full source is on GitHub if you'd rather build it yourself.

How fast are copies?

Usually 2–5 seconds after the trader's transaction confirms. For best results add a free RPC URL (Helius, QuickNode) and a free Jupiter API key in Settings → Execution.

Does the server PC need to be on the same network?

For "Find servers" and pairing, yes — same Wi-Fi or LAN. The server keeps trading on its own whether or not the desktop app is open.
